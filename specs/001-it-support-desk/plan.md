# Implementation Plan: Mesa de ayuda de soporte TI

**Branch**: `001-it-support-desk` | **Date**: 2026-10-09 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/001-it-support-desk/spec.md`

## Summary

Construir un MVP web de Nexo para una semana: usuarios autenticados crean y consultan sus reportes; técnicos listan todos los reportes, se asignan uno y avanzan su estado de abierto a en proceso y resuelto. El frontend será Angular, la API REST será Node.js con Express, los datos estarán en PostgreSQL y las suites serán Jasmine para Angular y Jest para la API. GitHub Actions ejecutará compilación y pruebas.

La interfaz de administración de categorías, administración de usuarios, notificaciones, reapertura y cancelación quedan fuera de este MVP. Las categorías `COMPUTER` y `NETWORK` se siembran en PostgreSQL por organización; el modelo y `GET /categories` quedan preparados para una futura interfaz administrativa.

## Technical Context

**Language/Version**: TypeScript, versión LTS compatible con Angular y Node.js; fijar versiones exactas en los manifiestos durante la implementación.

**Primary Dependencies**: Angular, Node.js, Express, PostgreSQL driver/query layer, Jasmine/Karma, Jest/Supertest.

**Storage**: PostgreSQL.

**Testing**: Jasmine/Karma para frontend; Jest/Supertest para API; validación de compilación en ambos proyectos.

**Target Platform**: Navegadores modernos para el frontend y un entorno Linux de ejecución para la API y PostgreSQL.

**Project Type**: Aplicación web con frontend y backend.

**Performance Goals**: El 95% de las consultas de listado debe mostrar resultados al usuario en menos de 2 segundos bajo la carga del MVP; creación, asignación y cambio de estado deben confirmar en menos de 2 segundos.

**Constraints**: Entrega en una semana; alcance limitado a crear/listar/asignar/cambiar estado; acceso diferenciado por rol y organización; no exponer credenciales ni secretos; categorías configurables en datos, pero sin interfaz administrativa; cambios de asignación y estado consistentes.

**Scale/Scope**: Varias organizaciones pequeñas, hasta 1,000 usuarios y 10,000 reportes por organización para el MVP; dos roles y categorías iniciales sembradas por tenant.
